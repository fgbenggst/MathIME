# MathIME v1.0.16 — 曲線交點與單字元診斷

- 改寫 `SingleGlyphRecognizer.kt`：兩筆曲線採用分段線段相交測試，不再要求整筆近似直線；再依筆畫整體方向判斷 `+` 與 `x`。
- 單筆 `2` 採用弧線、左下轉折及右側底線幾何條件；避免盲目猜測。
- `comer_diagnostics.txt` 追加 `SingleGlyph geometry`，包含筆畫數、外接框、交點、角度、拒絕原因或結果。
- 保留 CoMER 模型候選與原有 IME 功能。規則分類器不是訓練後的神經網路，對連筆、特殊書寫方向仍有侷限。
- 注意：若筆畫交叉但實際是 t，仍可能誤判為 +；請在候選列人工確認。
- 尚未於 Android SDK 編譯及手機測試。
