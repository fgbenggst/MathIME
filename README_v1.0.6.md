# MathIME v1.0.6 — 候選品質診斷版

以 v1.0.5 為基礎，保留原始筆跡、輕度平滑、保守字形修正、離線 CoMER ONNX、MathJax、鍵盤輸入及候選預覽。

- Beam width 9，每種影像最多保留 6 個候選；合併後最多 9 個不同公式。
- 不跨前處理版本直接比較模型分數；按各版本局部名次、LaTeX 結構和多版本一致性重新排序。
- 不硬編碼刪除 E、i、π，不自行拼接或偽造 AI 辨識結果。
- 診斷用原始三種變體 PNG 儲存至 app 私有檔案目錄 mathime_input_variant_0.png 等。這些是送入前處理前的筆跡圖，並非最終 512x256 tensor 的逐像素影像。
- 保持 pixel_mask 全 false，保留數值診斷。

注意：辨識準確率未經實測驗證，更多候選可能增加耗時。診斷 PNG 位於 App 私有儲存空間，尚未提供直接分享圖片按鈕。
