# MathIME v1.0.15 — 獨立單字元幾何辨識器

加入 SingleGlyphRecognizer.kt，使用觸控筆畫座標進行離線幾何辨識；與 CoMER ONNX 公式辨識器並行。
目前保守支援兩筆直線的 + 與 x，以及實驗性的單筆 2。當幾何規則匹配時將其列為第一候選，原 CoMER 結果仍保留供切換。其分數是規則信心指標，不是經過校準的統計機率。

本版沒有下載或訓練新的神經網路模型，不能宣稱對所有單字元有效。請特別測試交叉筆畫的 x/+、單筆 2 與複雜公式的誤觸發。若需更高準確率，下一步是蒐集帶標籤的實際手寫資料，訓練專門的單字元模型。

保留原有離線 CoMER、橡皮擦、候選、公式預覽與診斷分享。GitHub Actions 可使用既有 workflow 編譯。
