# MathIME v1.0.21 (experimental)

Based on v1.0.20. Keeps CoMER ONNX models and original keyboard functions.

- Adds conservative alternate grouping of adjacent strokes for short horizontal expressions.
- Adds a separate top-bar + hooked-body recognizer for handwritten digit 5.
- Retains fraction-bar guard and abstains when shape confidence is insufficient.
- Adds GitHub Actions workflow for building APK from phone uploads.

**Not Android compiled or device validated.** Please test 2x, 3x, 5x and dx/dy before replacing a working installation.
