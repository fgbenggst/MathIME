# MathIME v1.0.17 — 筆畫分組辨識實驗版

- 新增 `GroupedGlyphRecognizer.kt`，以筆畫外接框的交疊及空間順序分組。
- 每個群組獨立交由單字元幾何辨識器；另有保守的單筆手寫 `3` 規則，目標改善 `3x`。
- **僅當所有群組皆可辨識**，才把分組結果加入候選第一位。原 CoMER 候選仍保留。
- 診斷分享新增 `GroupedGlyph`：筆畫數、群組筆畫數、各群組結果與拒絕原因。
- 保留 v1.0.16 原有橡皮擦、復原、離線模型、候選、快速／精準模式與 PNG 分享。
- 限制：幾何分組不等於通用公式排版分析，分數線、根號、上下標及連筆符號可能不適用；`3` 規則未經資料集驗證，需人工核對。
- 尚未在 Android SDK 編譯或手機實測。
