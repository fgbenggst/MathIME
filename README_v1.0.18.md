# MathIME v1.0.18 — 分組辨識改善

此為完整 Android 原始碼專案，含 encoder_int8.onnx、decoder_int8.onnx、vocab.json 和離線 MathJax。

更新：
- 對單筆 `2` 與 `5` 加入保守幾何判斷，保留 v1.0.17 的 `3` 及 `x`。
- 當長水平筆畫分隔上下區域時，分組辨識器放棄判斷，避免把分式錯認成左右字元。
- 分組候選與 CoMER 候選保留並去除重複，最多九個。
- 保留診斷文字與模型輸入 PNG 分享、橡皮擦、復原、快速／精準模式、LaTeX 編輯與公式預覽。

注意：規則式單字元辨識是實驗功能，非訓練完成的字元分類模型，對筆跡的適用性有限。
本包已進行原始碼及 ZIP 完整性檢查，尚未完成 Android Gradle 編譯或實機測試。
