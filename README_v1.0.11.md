# MathIME v1.0.11 — 單字元診斷與低可信度提示

基於 v1.0.10 橡皮擦版本，保留 CoMER 離線模型、手寫鍵盤、候選、預覽、快速／精準模式及橡皮擦。

新增：在解碼器前五步的第一條 beam，輸出 x、2、+、I、i、E、\\pi、<eos> 的排名與 softmax 機率；對第一候選中 I/i/E/\\pi/\\sum 集中出現的情況標示「辨識不確定」。這是啟發式警示，不是校準過的辨識機率。

本版不強制替換合法符號、不假造單字元辨識結果，亦未聲稱已修復模型偏好。快速模式維持原本的 1 張圖片、beam width 3，保留 1–2 秒的目標。

本環境沒有 Android Gradle 工具鏈，尚未編譯 APK；請用 GitHub Actions 編譯並回報測試診斷。
