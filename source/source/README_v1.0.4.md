# MathIME v1.0.4 — 候選品質與預覽介面修正

- 版本號 `1.0.4` / versionCode `24`。
- 保留真實 CoMER ONNX encoder/decoder、全 false 的有效 pixel_mask。
- Beam Search 內部寬度提升到 5，最多呈現 3 個不同候選。
- 針對重複單一英文字母與重複 token 片段加入軟性懲罰。
- 對大括號與圓括號不平衡候選降權，不會刪除任何預測字元。
- 預覽左右候選箭頭縮窄至 38dp，增加公式可視寬度。
- MathJax 語法錯誤時顯示提示而非黑色錯誤公式。

## 注意

這些是啟發式候選排序修正，不是重新訓練 AI。不能保證移除多餘的 E 或提升所有題型的準確率。尚未在 Android 上編譯或實機測試。
