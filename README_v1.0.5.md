# MathIME v1.0.5 — 手指筆跡優化實驗版

保留 v1.0.4 的離線 CoMER ONNX、MathJax 預覽、候選切換、輸入法與診斷。

## 本版改動
- 原始筆跡：完全保留，優先列入候選。
- 輕度平滑：使用觸控軌跡去抖，保留折角。
- 保守字形修正：較強平滑及較細線條，**不推斷或替換符號身份**。
- 每個版本都經同一個 CoMER 模型辨識，合併去重候選；最多九組（每版最多三組）。
- 預覽區左右箭頭切換候選，狀態列顯示候選來源。
- 版本名稱 1.0.5，versionCode 25。

## 重要限制
這是前處理實驗，**不是真正的字元級辨識／字形重建模型**。不同圖片的模型分數不能直接作為可靠的跨圖排序依據；本版優先原圖結果，其餘作為候選。三次模型推論可能明顯變慢。尚未在 Android 裝置編譯或測試。

## 編譯
把專案推送到 GitHub，透過 `.github/workflows` 內既有 Actions 建置。模型與 MathJax 已打包於 `app/src/main/assets`。
